
# Interactive To-Do List Application

## About the Project
This is a simple and interactive To-Do List Application developed as part of the eMobilis JavaScript Practical Assignment.

The application allows users to manage their daily tasks by adding, completing and deleting tasks.

## Technologies Used
- HTML5 - Structure of the application.
- CSS3 - Styling and layout.
- JavaScript - Functionality and interactivity.

## Features
- Add new tasks.
- Display all tasks.
- Mark tasks as completed.
- Delete individual tasks.
- Input validation to prevent empty tasks.
- Task counter.
- Clear all tasks.
- Save tasks using localStorage.

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your web browser.
4. Start adding and managing your tasks.
